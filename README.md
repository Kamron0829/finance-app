# Moliya: личные финансы (Android)

Приложение для личного учёта финансов: капитал, цели (машина, недвижимость, подушка), платежи, долги, инвестиции,
автоучёт по банковским SMS, ежедневные уведомления и «Отчёт для ИИ» для Claude. Все данные хранятся только на телефоне.

## Как установить на телефон
1. Открой вкладку **Releases** этого репозитория на телефоне и скачай последний `moliya-N.apk`.
2. Открой файл. Android попросит разрешить установку из этого источника (браузер / Telegram): разреши.
3. При первом запуске разреши уведомления. Чтобы включить автоучёт, открой «Ещё → SMS от банков» и разреши доступ к SMS.

Обновление: скачай новый APK и установи поверх старого. Данные сохранятся.
Перед обновлением на всякий случай сделай «Ещё → Настройки → Сохранить копию».

## Как собирается APK
Каждый push в `main` запускает GitHub Actions (`.github/workflows/build-apk.yml`):
type-check → тесты парсера SMS → `expo prebuild` → `gradlew assembleRelease` → APK в Releases.

## Разработка
```bash
npm install
npm run typecheck
npm run test:sms        # тесты разбора банковских SMS
npx expo start --web    # быстрый просмотр интерфейса в браузере (SMS и уведомления там не работают)
```

## Структура
- `src/types.ts` модель данных (та же, что в finance_state.md для Moliya)
- `src/store.ts` хранилище на телефоне (AsyncStorage + zustand)
- `src/calc.ts` расчёты: капитал, свободный поток, норма сбережений, DSTI, цели с инфляцией, индекс здоровья, уровни
- `src/smsParse.ts` разбор SMS (рус / узб / англ), `modules/sms-reader` нативный модуль чтения входящих SMS (только чтение)
- `src/export.ts` отчёт для ИИ (Markdown) и резервная копия (JSON)
- `src/notifications.ts` ежедневные уведомления и напоминания о платежах
